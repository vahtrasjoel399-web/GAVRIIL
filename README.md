# Книга подарков для Гавриила

Интерактивная книга ко дню рождения: коробки в коробках → ключ → замок с вопросом →
турнир в букмекерском приложении → «Альбом Гавриила» (милые фото и видео), к которому можно возвращаться.

Стек: Vite + React + TypeScript, анимации — [Motion](https://motion.dev), конфетти — canvas-confetti.
Перелистывание страниц — собственный движок (`src/book/`): реалистичный загиб, тень на сгибе,
свайп на телефоне, клик по краю и стрелки на компьютере.

## Запуск

```bash
npm install
npm run dev        # локально: http://localhost:5173
npm run build      # проверка TypeScript + сборка в dist/
npm run preview    # посмотреть собранную версию
```

`dist/` — обычные статические файлы для любого хостинга (Netlify, Vercel, GitHub Pages).
На сайте стоит `noindex`: поисковики его не покажут.

## Где менять содержимое

Весь текст, фото и цифры лежат в `src/content/`. Компоненты ничего не знают о Гаврииле —
достаточно править эти файлы. Подсказки по полям — в `src/content/types.ts`.

| Файл | Что внутри |
| --- | --- |
| `boxes.ts` | Коробки: подписи, записки, тексты кнопок, цвета. Количество коробок — любое |
| `lock.ts` | Вопрос на замке, правильные ответы, подсказка, запись на полях для «Сдаюсь» |
| `album.ts` | Альбом: страницы по 1–2 фото или видео, подписи, заметки на полях, последняя страница |
| `tournament.ts` | Приложение GavriBet: участницы (любое количество, все играют с первого раунда), ставка, выигрыш, тексты |
| `media.ts` | Фоновая музыка (несколько песен по очереди) и песни из Spotify в плеере в углу |
| `site.ts` | Заголовок вкладки, описание и превью ссылки |

### Фото и видео

Фото альбома лежат в `public/media/photos/gavriil/`, видео с обложками — в `public/media/video/album/`,
список страниц — в `album.ts`. `ratio` — ширина / высота (3/4 — вертикальное, 3/2 — горизонтальное).
Видео лучше в MP4 (H.264 + AAC). Пока оно играет, фоновая музыка затихает.

### Ответ на замке

Ответ проверяется без учёта регистра, пробелов, «ё/е» и раскладки: «ufdhbr», набранное
в английской раскладке, засчитывается как «гаврик». Подсказка появляется после двух ошибок.

### Ссылка для мессенджеров

Укажите адрес опубликованного сайта в `url` в `src/content/site.ts` — тогда превью
(`public/og-image.png`) будет надёжно показываться при отправке ссылки.

## Как это работает

- **Прохождение сохраняется** в браузере: после турнира при следующем заходе сразу открывается
  альбом; на его последней странице есть ссылка «Пройти всё сначала».
- **Телефон**: одна страница, листается свайпом. **Компьютер**: разворот, листается кликом
  по краю страницы, перетаскиванием уголка и стрелками ← →.
- **Звук страниц и музыка** включаются и выключаются кнопками в правом верхнем углу;
  выбор запоминается.
- Если в системе включено «уменьшение движения», страницы сменяются мягко, без загиба и конфетти.

## 3D-картинки (Blender)

Коробки, ключ, кожаная книга и замок отрендерены в Blender скриптом
`scripts/blender/render_assets.py` → `public/media/3d/*.webp`. Цвета коробок скрипт берёт
из `boxes.ts`, название книги — из `lock.ts`. После их изменения перерендерите:

```bash
/Applications/Blender.app/Contents/MacOS/Blender -b --factory-startup -P scripts/blender/render_assets.py
# быстрый черновик: добавьте  -- --preview   ;  только часть:  -- --only box,key,book,padlock
```

## Заглушки

Фоновая музыка пока — синтезированная заглушка (`public/media/audio/placeholder-theme.mp3`).
Абстрактные картинки в `public/media/placeholders/` создаются командой `npm run media:placeholders`.
