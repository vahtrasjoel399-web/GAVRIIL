# История жизни — интерактивный сайт

Цифровая история человека год за годом: от года рождения до сегодняшнего дня.
Хроника с анимированными фотографиями, кино, карточки воспоминаний, галерея,
подарки, торт со свечами и спрятанный секрет.

Стек: Vite + React + TypeScript, анимации — [Motion](https://motion.dev), конфетти — canvas-confetti.

## Запуск

```bash
npm install
npm run dev        # локально: http://localhost:5173
npm run build      # проверка TypeScript + сборка в dist/
npm run preview    # посмотреть собранную версию
```

`dist/` — обычные статические файлы: подойдёт любой хостинг (Netlify, Vercel, GitHub Pages, свой сервер).

## Где менять содержимое

Вся информация о человеке лежит в `src/content/`. Компоненты ничего не знают
о конкретном человеке — достаточно править эти файлы.

| Файл | Что внутри |
| --- | --- |
| `person.ts` | Имя, дата рождения, тексты вступления, заголовки разделов, финал (поздравление, пожелания, число свечей) |
| `timeline.ts` | Главы по годам: заголовок, история, «читать дальше», цитата, фото, цвет, отметка-праздник с конфетти |
| `gallery.ts` | Дополнительные фото для галереи (фото из глав попадают туда автоматически) |
| `memories.ts` | Карточки воспоминаний (лицевая сторона и история на обороте) |
| `gifts.ts` | Подарки: письмо, сертификат с кодом или фотография |
| `media.ts` | Видео (файл, постер, главы) и фоновая музыка |
| `secret.ts` | Секрет: кодовое слово, число нажатий на звезду в подвале, текст |
| `site.ts` | `<title>`, description, Open Graph — подставляются в `index.html` при сборке |
| `types.ts` | Описание всех полей (подсказки появятся прямо в редакторе) |

### Фотографии

1. Положите файлы в `public/media/photos/` (jpg, webp, png — любые).
2. В `timeline.ts` укажите путь от папки `public`, описание и пропорции:

```ts
{ src: '/media/photos/2005-dacha.jpg', alt: 'На даче у бабушки', caption: 'Лето 2005', ratio: 4 / 5 }
```

`ratio` — ширина / высота (4/5 — вертикальное, 3/2 — горизонтальное, 1 — квадрат).
Нужен, чтобы страница не «прыгала», пока фото загружаются. В главе показываются до трёх фото.

### Видео и музыка

Файлы — в `public/media/video/` и `public/media/audio/`, пути — в `src/content/media.ts`.
Лучше всего работает MP4 (H.264 + AAC). Главы видео (`chapters`) — время в секундах и подпись.
Пока играет видео, фоновая музыка плавно затихает и потом возвращается.

### Метаданные и ссылка для соцсетей

В `src/content/site.ts` укажите `url` опубликованного сайта — тогда Open Graph-картинка
получит абсолютный адрес и превью в мессенджерах будет работать надёжно.
Картинка превью — `public/og-image.png` (1200×630), иконка — `public/favicon.svg`.

## Плейсхолдеры

Сейчас на сайте демо-контент: абстрактные картинки, синтезированная музыка и видео
с градиентами. Картинки создаёт `npm run media:placeholders` — после замены на
настоящие фото этот скрипт и файлы `public/media/photos/*.svg` можно удалить.

Демо-тексты написаны без указания рода. Если в настоящих историях встречаются
глаголы прошедшего времени — используйте нужную форму.

## Управление

| Клавиша | Действие |
| --- | --- |
| `→` / `J`, `←` / `K` | Следующая / предыдущая глава |
| `M` | Музыка вкл/выкл |
| `?` | Подсказка по клавишам |
| `Esc` | Закрыть окно |
| `←` `→` в просмотре фото | Листать (на телефоне — свайп) |
| `Пробел` / `K`, `F`, `M` в плеере | Пауза, весь экран, звук |

Анимации автоматически сокращаются, если в системе включено «уменьшение движения».
Это можно переключить вручную в меню → «Настройки → Анимации».

Секрет открывается кодовым словом (по умолчанию `magic` — работает и на русской раскладке)
или несколькими нажатиями на едва заметную звезду в подвале.
