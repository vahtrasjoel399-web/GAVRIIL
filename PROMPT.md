# Промт: интерактивная книга ко дню рождения Гавриила

**Контекст.** В этой папке уже есть сайт ко дню рождения: Vite + React + TypeScript, анимации — Motion,
конфетти — canvas-confetti, весь контент — в `src/content/*.ts`. Его нужно переделать под новый сценарий ниже.
Готовые части — просмотр фото, видеоплеер, фоновую музыку, конфетти, мета-теги — переиспользовать.
Хронику по годам, карточки воспоминаний, подарки и торт из основного сценария убрать.

**Для кого.** Гавриил (Гаврика) — наш друг. Тексты на русском, обращение на «ты», мужской род.
Тон тёплый, с юмором нашей компании.

## Главное правило стиля

Всё, кроме турнира и ставок, оформлено как **книга**: страницы перелистываются с реалистичным загибом
и тенью на сгибе, бумажная текстура, номера страниц, рукописные заметки на полях, фото — как вклеенные
полароиды на скотче. На телефоне видна одна страница и листается свайпом, на компьютере — разворот,
листается кликом по краю страницы и стрелками. Есть звук перелистывания, его можно выключить.

Турнир и казино — нарочно контрастный «другой мир»: тёмный неоновый интерфейс букмекерского приложения.

## Сценарий

### 1. Коробки
- Первая страница: закрытая коробка-подарок и подпись «С днём рождения, Гавриил!».
- Клик по коробке — она открывается (крышка слетает, немного конфетти), внутри записка и кнопка.
- Кнопка перелистывает страницу, там следующая коробка, поменьше. Так 4 раза; количество коробок
  и тексты записок задаются в контенте. Записки с подколами: «Слишком просто. Дальше», «Почти…»,
  «Ладно, последняя».
- В последней коробке лежит старый ключ.

### 2. Переход к историям группы
- Ключ подходит к замку на книге «Хроники нашей группы»: кожаная обложка, тиснение, замок.
- Чтобы открыть замок, нужно ответить на вопрос, который знают только свои. В контенте: вопрос,
  правильные ответы (без учёта регистра и раскладки), подсказка после 2 ошибок. Кнопка «Сдаюсь»
  тоже открывает книгу, но со смешной записью на полях.
- Замок щёлкает, обложка открывается — начинаются истории.

### 3. Истории группы (книга)
- Каждая история — разворот: слева 1–3 фото-полароида (по клику — на весь экран), справа заголовок,
  дата, текст и кто рассказывает. По желанию — «мем группы» на полях.
- В начале главы — оглавление, сбоку — закладка-ленточка для быстрого перехода.
- Последняя страница: «Но это ещё не всё…».

### 4. Турнир девушек Гавриила (не книга)
- Переход: при перелистывании последней страницы поверх книги выскакивает спам-баннер букмекера
  («🎰 Эксклюзивное предложение для Гавриила!»), книга уезжает, открывается приложение.
- Интерфейс в стиле онлайн-казино и букмекеров вроде NinjaCasino: тёмный фон, неон, плашки
  коэффициентов, бейджи LIVE. Название и логотип **вымышленные** (например, «GavriBet»):
  бренд NinjaCasino не копировать.
- Событие «Турнир девушек Гавриила», рынок «Победитель». Участницы — карточки: фото, имя или прозвище,
  коэффициент (например 1.85 / 3.40 / 12.00) и смешная «статистика».
- Гавриил выбирает первое место → снизу выезжает купон ставки → «Ставка принята» → короткая
  драматичная «трансляция» → «Ставка сыграла!» и конфетти.
- Выигрыш всегда равен заданной сумме (по умолчанию 60 €); ставка считается сама: сумма / коэффициент.

### 5. Вывод средств
- Экран кошелька: баланс 60,00 €, кнопка «Вывести».
- Окно вывода: сумма 60 € и кнопка «Подтвердить». Никаких полей для карты или реквизитов — только кнопки.
- Загрузка → «Средства выведены ✅ Транзакция может занять до 5 минут».
- Через пару секунд появляется кнопка «Что дальше?»: приложение закрывается, возвращается книга.

### 6. Выбор: «Мотивация» или «Гавриил» (книга)
Страница с двумя большими кнопками-закладками:
- **Гавриил** — «Если тебе плохо или кажется, что ты никому не нужен, — загляни сюда».
  Внутри только его фотографии, в основном детские, как семейный альбом. Минимум текста:
  смысл в том, чтобы вспомнить себя маленьким.
- **Мотивация** — «Если нужен пинок вперёд». Фото и видео (видео играет прямо на странице,
  фоновая музыка на это время затихает) и короткие слова от друзей.

Из каждого раздела можно вернуться к выбору.

### 7. Возвращение
В эти два раздела Гавриил будет возвращаться. Прохождение сохраняется в localStorage: при следующем
заходе сразу показывается выбор «Мотивация / Гавриил» и маленькая ссылка «Пройти всё сначала».
У разделов свои адреса (`#motivation`, `#gavriil`), чтобы их можно было добавить в закладки.

## Технически
- Mobile-first: ссылку, скорее всего, откроют с телефона. Проверить на ширине 360–430 px и на компьютере.
- Перелистывание — библиотека page-flip (StPageFlip) или своя реализация на CSS 3D + Motion.
  Главное, чтобы плавно работало на телефоне.
- Учитывать системную настройку «уменьшение движения»: вместо загиба — мягкая смена страниц.
- Весь контент — в `src/content/*.ts` с типами: тексты записок в коробках, вопрос и ответы для замка,
  истории группы, участницы турнира и коэффициенты, сумма выигрыша, тексты вывода, фото для «Гавриил»,
  фото и видео для «Мотивации». Пока нет настоящих материалов — ставить заглушки и ничего не спрашивать.
- Добавить `<meta name="robots" content="noindex">`: на сайте будут фото реальных людей.
- В конце: `npm run build` без ошибок, весь сценарий пройден в браузере на телефоне и на компьютере.
